# macOS Sequoia Lab

Custom tweaks, configurations, and scripts for running **macOS Sequoia** on a Late 2013 MacBook Pro using OpenCore Legacy Patcher.

## System Specs
- MacBook Pro 15" Late 2013
- 2TB Samsung 990 Pro SSD
- 16GB RAM
- macOS Sequoia (non-beta)
- OpenCore Legacy Patcher: Nightly Build

## Features
- Full Sequoia install on unsupported Mac
- TRIM enabled and working with NVMe
- Carbon Copy Cloner for full backups and restores
- Dev-ready environment with Homebrew, Git, Raycast, and more
